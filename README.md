# Journalism Portfolio

A minimal journalism portfolio built with HTML and CSS.

## Pages

- `index.html` — homepage with bio and social links
- `articles.html` — article links
- `audio.html` — audio links
- `data-projects.html` — data project links
- `styles.css` — site styling

## How to update

Edit the HTML files directly to replace placeholder text and links.

## Publishing on GitHub Pages

Upload these files to a GitHub repository and enable GitHub Pages from:

Settings → Pages → Deploy from a branch → main → /root
